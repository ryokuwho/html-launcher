# html-launcher


スマホやPCのブラウザ上で動作する、自分だけのHTMLツール・ミニゲーム管理ランチャーです。お気に入りの単一HTMLファイルを手軽に登録・整理・起動できます。

🚀 主な機能
ファイル・ツールの一元管理: HTMLファイルをアップロードするだけで、タイトルや登録日、優先度をつけたリストとして管理できます。

スムーズなビューア機能: 登録したアプリをワンタップで専用ビューア（iframe）上で即座に実行・プレビュー可能です。

柔軟な並び替えと検索:

優先度順、名前順、登録日順でのソート

昇順・降順の切り替え

キーワードによるリアルタイム検索

安心のデータバックアップ:

登録データをJSON形式でいつでもエクスポート（書き出し）可能。

別の端末やブラウザ、過去のバックアップファイルからのインポート（読み込み）にも対応しています。

レスポンシブデザイン: スマートフォンでの操作に最適化された、ダークテーマベースの洗練されたUI。

📱 使い方
右上の ＋ ボタン から、管理したいHTMLファイルを選択して追加します。

リスト上の項目をタップすると、フルスクリーンでアプリが起動します。

リストの歯車・数値入力部分で「優先度」を変更できます。

データの移行やバックアップは、上部の矢印アイコン（エクスポート／インポート）から簡単に行えます。
